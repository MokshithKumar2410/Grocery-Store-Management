# 🛒 Grocery Store Management Analysis | SQL Project

## 📌 Project Overview

Every grocery store generates thousands of transactions every day. Behind every transaction lies valuable information that can help businesses understand customers, products, suppliers, and sales performance.

This project focuses on analyzing a **Grocery Store Management relational database using SQL** to transform transactional data into meaningful business insights and support better decision-making.

---

## 📖 Back Story Behind the Project

As a grocery business grows, the volume of transactional data also increases. The challenge is not simply collecting data, but using it to answer important business questions.

The business wanted to understand:

* Who are the most valuable customers?
* Which products and categories generate the highest revenue?
* Which suppliers contribute the most to sales?
* How are sales changing over time?
* How can sales trends support better inventory planning?

Without structured analysis, these insights can remain hidden, making business decisions slower and less effective.

---

## 🎯 Business Problem

The grocery store lacked a data-driven approach to analyze:

* Customer purchasing behavior
* Product and category performance
* Supplier contribution
* Employee and order activity
* Sales and revenue trends

This limited the business's ability to identify growth opportunities and improve operational efficiency.

---

## 🎯 Project Objective

To analyze the Grocery Store Management database using **SQL** and transform raw transactional data into actionable business insights for better decision-making.

---

## 🗂️ Database Structure

The project uses a relational database consisting of the following tables:

| Table          | Description                                                   |
| -------------- | ------------------------------------------------------------- |
| `Customers`    | Contains customer information                                 |
| `Products`     | Contains product details and pricing                          |
| `Categories`   | Contains product category information                         |
| `Suppliers`    | Contains supplier details                                     |
| `Employees`    | Contains employee information                                 |
| `Orders`       | Contains customer order information                           |
| `OrderDetails` | Contains individual products and quantities within each order |

The relationships between these tables allow customer, product, supplier, employee, and sales data to be analyzed together.
